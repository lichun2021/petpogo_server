# 后台字号规范

使用 Tailwind 语义字号，由 app/assets/css/main.css 集中定义。以下像素值以浏览器根字号16px为准，实际使用rem以支持用户缩放。

| 用途 | 类名 | 字号 / 行高 |
| --- | --- | --- |
| 分类、状态标签，日期、地址、编号及辅助说明 | text-xs | 13 / 20px |
| 列表正文、表头、常规操作 | text-sm | 14 / 22px |
| 区块及弹窗标题 | text-base | 16 / 24px |
| 页面主标题 | text-xl | 20 / 28px |
| 仪表盘、统计卡数字 | text-2xl | 28 / 36px |

- 不使用 text-[8px]、text-[10px]、text-[11px] 等任意小字号展示业务文字。
- UBadge 的 xs/sm/md 字号统一13px，大小差异由内边距表达；lg为14px，xl为16px。配置位于 app/app.config.ts，避免使用组件默认的8px/10px。
- 表格和使用 CSS grid 的列表表头统一14px，不与日期、地址等辅助文字共用小字号。
- 图标、表情和验证码画布的尺寸不属于文字层级，不随上述替换统一缩放。
- 新增列表优先沿用现有行间距；长文本保持原换行/截断逻辑，不通过缩小字体容纳。

本轮验证：后台页面与布局无10px/11px任意文字类；按Nuxt UI相同合并方式核对标签xs/sm/md/lg/xl实际类名；TypeScript检查与Nuxt构建通过。未执行登录后的各页浏览器视觉回归，也未部署线上。
